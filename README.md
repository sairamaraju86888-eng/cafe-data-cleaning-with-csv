# ☕ Cafe Sales Data Cleaning with Python & Pandas

This project focuses on real-world **data cleaning and preprocessing** using Python and Pandas on a dirty cafe sales dataset. The dataset contains missing values, invalid entries, inconsistent formatting, duplicate records, and datatype issues commonly found in raw business data.

## 🚀 Project Overview

In this project, I performed a complete end-to-end data cleaning workflow including:

* Handling missing values
* Replacing invalid values (`ERROR`, `UNKNOWN`)
* Removing duplicates
* Converting datatypes
* Cleaning
* Feature engineering
* Data validation
* Exporting a cleaned CSV dataset

The goal of this project is to demonstrate practical **data preprocessing techniques** used in real-world Data Science and Data Analytics projects.
